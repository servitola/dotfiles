# Key by key

Birman's own annotated poster, with the reasons behind the characters: <https://ilyabirman.ru/typography-layout/poster/>.

The key with ⌥ types the lower character, with ⇧⌥ the upper one. A key in a grey box in the picture is a
dead key: press the accent, then a letter.

| What | How |
| --- | --- |
| em dash `—` / en dash `–` | ⌥ + `-` / ⇧⌥ + `-` |
| minus `−` / bullet `•` | ⌥ + `m` / ⇧⌥ + `m` |
| multiplication `×` | ⌥ + `x` |
| guillemets `«` `»` | ⌥ + `,` / ⌥ + `.` |
| low and high double quotes `„` `“` | ⇧⌥ + `,` / ⇧⌥ + `.` |
| single quotes `‘` `’` | ⇧⌥ + `k` / ⇧⌥ + `l` |
| angle quotes `‹` `›` | ⇧⌥ + `9` / ⇧⌥ + `0` |
| non-breaking space | ⌥ + space |
| `©` `®` `™` | ⌥ + `c` / `r` / `t` |
| `€` `₽` `£` `$` `¢` | ⌥ + `e` / `h` / `f` / `4`, ⇧⌥ + `c` |
| `°` `‰` `′` `″` | ⌥ + `d` / `5` / `p`, ⇧⌥ + `p` |
| `≈` `≠` `±` `∞` | ⌥ + `a` / `=`, ⇧⌥ + `=`, ⌥ + `8` |
| arrows `←` `↑` `→` `↓` | ⌥ + `9` / `6` / `0` / `v` |
| `✓` `§` `ß` | ⌥ + `w` / `s` / `b` |
| pre-1918 Russian `ѣ` `ѳ` `ѵ` `і` | ⌥ + `y` / `o` / `u` / `i`, capitals with ⇧ |
| fractions `¹⁄₂` `¹⁄₃` `¹⁄₄` | ⇧⌥ + `2` / `3` / `4` |
| `¡` `¿` | ⇧⌥ + `1` / `7` |

Letters are QWERTY positions: the layer is positional, as on Windows.
