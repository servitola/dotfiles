# docs — human/agent reference docs for the dotfiles setup, read selectively

- These are reference docs, not config — read the specific file relevant to a question rather than ingesting the whole tree. The live source of truth is the actual config dirs (`hammerspoon/`, `karabiner/`, `homebrew/`, the `Makefile`); docs describe and orient.
- `repo-map.md` — every top-level directory ranked by importance, the default apps and the always-on services; start here.
- `keyboard-setup.md` — the keyboard system: Karabiner-Elements remapping (Caps Lock → Hyper = all 4 right modifiers), Apple's layouts with BirmanLayer.spoon's right-⌥ typographic layer, and Hammerspoon catching key events to launch apps/run functions. Source-of-truth pipeline: karabiner → birman → hammerspoon.
- `hammerspoon.md` — Hammerspoon automation: Spoon system, HotKeys spoon, Lua scripting against macOS APIs.
- `homebrew.md` — package management notes; points at `homebrew/brewfile` and install scripts as the real data.
- `keyboard/` — auto-generated SVG layer diagrams (one per modifier combination) plus `README.md` legend. Regenerate, do not hand-edit, via `python3 docs/keyboard/generate.py`.
- `keyboard/` Python modules build the SVGs from config (`parse_karabiner.py`, `parse_birman.py` — what each key types, from `keyboard/apple-layouts/` and the installed BirmanLayer.spoon table — `svg_*.py`, etc.); `keyboard/tools/` holds `lint.py` (format/coverage checks on the HotKeys layout `.lua`, plus bridge/layer checks), `gen_layers.py` (regenerates Karabiner rules 07–17 from `karabiner/layers.toml`, including its `[slots]`), `normalize.py` (rewrite layout files to canonical ASCII), `bridge.py` (the bridge slot table: every F13–F20/keypad code, the chord behind it and what binds it), `where.py <chord>` (one chord across Karabiner, the layout files, `shortcuts.toml` and the layouts' characters), and `dump_apple_layouts.py` (refreshes `keyboard/apple-layouts/` from macOS after an update). Machine hotkeys outside the repo (`shortcuts.toml`, read by lint S1–S4) live in `macos_shortcuts/`; `keyboard/projection.py` writes them, and Rider's keymap (`keyboard/rider.py`, repo copy `jetbrains rider/keymap.xml`), into the layout tables as `⚙` / `◆` / `ℝ` lines (`normalize.py --project`, lint P1/S5). Run these against the Hammerspoon layout, not against the docs.
