# Dotfiles Vision

## North Star

Эти dotfiles — операционная система поверх macOS. Не набор конфигов, а живая, эволюционирующая система управления рабочей средой.

## Принципы

### 1. Всё делается само
- Установка, обновление, миграция — одна команда (`make`, `up`)
- Новый Mac = клон репо + `make` = полностью готовая рабочая среда
- Нет ручных шагов, которые нужно "помнить". Если что-то нужно делать руками — это баг

### 2. Стабильность на годы
- Конфигурации должны пережить смену macOS, смену железа, смену username
- Не зависеть от конкретных версий инструментов там, где возможно
- Обратная совместимость: изменения не ломают существующее поведение
- Каждое решение документировано в memory — чтобы через год было ясно, почему так

### 3. Легко и надёжно менять
- Модульная структура: одна папка = один инструмент
- Единая точка правды для каждой настройки (no duplication)
- Makefile как декларативный манифест: добавил строку = добавил интеграцию
- Karabiner генерируется из правил, а не редактируется монолитом
- Изменение одного инструмента не задевает остальные

### 4. AI — полноправный оператор
- AI (Claude, Qwen), запущенный из этой папки, может управлять всей системой
- Shared skills/commands/agents в `claude-code/` — единый источник для всех AI-инструментов
- Memory (этот каталог) — персистентная база знаний AI о системе
- AI знает архитектуру, ограничения, предпочтения — и действует автономно
- Цель: сказать "настрой X" — и AI сделает всё сам, включая Makefile, симлинки, документацию

## Направления развития

### Автоматизация
- Больше проверок в `up`: здоровье симлинков, актуальность конфигов
- Автоматическое обнаружение drift между репо и системой
- Self-healing: если симлинк сломался — восстановить автоматически

### AI-возможности
- AI может добавлять новые приложения по шаблону
- AI может менять клавиатурные шорткаты через layout-файлы
- AI может диагностировать проблемы (Hammerspoon логи, brew doctor, симлинки)
- AI может обновлять memory по результатам работы

### Надёжность
- Тесты для критических путей (симлинки существуют, shell грузится, hotkeys работают)
- Версионирование: всё в git, всё можно откатить
- Миграция между машинами без потерь
