# Настройка

## Основное

После `start()` ничего не обязательно. Две правки бывают нужны чаще всего; задайте их до `start()`:

```lua
hs.loadSpoon("BirmanLayer")
local layer = spoon.BirmanLayer
layer.excludedBundles = { "com.example.game" }   -- приложения, где слой молчит
layer.excludedLayouts = { "com.apple.keylayout.Greek" }   -- раскладки со своим слоем ⌥
layer.rightOptionOnly = false                    -- оба ⌥, как в Mac-раскладке Бирмана
layer:start()
```

Настройки читает `start()`; после изменения вызовите его ещё раз. Методы: `start()`, `stop()`, `state()`
(`running`, ожидающая мёртвая клавиша).

## Расширенные настройки

### Все настройки

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `overrides` | `{}` | правки таблицы Бирмана, см. ниже |
| `rightOptionOnly` | `true` | слой только на правом ⌥ (как на Windows); `false`: на обоих ⌥, как в Mac-раскладке Бирмана |
| `baseFixups` | `false` | печатать символы Бирмана на обычных и Shift-клавишах там, где ABC и Russian – PC от него отличаются (ISO-клавиатуры) |
| `excludedBundles` | `{}` | bundle ID приложений, где ничего не перехватывается |
| `excludedLayouts` | `{}` | id источников ввода (`hs.keycodes.currentSourceID()`), где слой не участвует и ⌥ печатает символы самой раскладки: у Apple Greek на ⌥ буквы с тоном (`ά έ ή`) и греческие знаки |
| `deadKeyTimeout` | `3` | сколько секунд ждёт мёртвая клавиша |
| `logger` | `hs.logger.new("BirmanLayer")` | логгер Spoon |

### overrides

`overrides` задаётся ключом `"*"` (любой источник ввода) или id одного источника ввода, как его печатает
`hs.keycodes.currentSourceID()` (`com.apple.keylayout.Greek`). Таблица источника лежит поверх `"*"`, та поверх
таблицы Бирмана. Каждое значение устроено как собственная таблица Spoon:

```lua
layer.overrides = {
    ["*"] = {
        keys = {
            g = { opt = "©", shift_opt = "℗" },        -- имена клавиш это позиции QWERTY (a, 1, [, space, section) или коды клавиш
            x = { opt = false },                       -- ничего не печатает
            ["1"] = { opt = { pass = true } },         -- оставить клавишу родному слою ⌥ Apple
            ["/"] = { shift_opt = { dead = "acute" } }, -- войти в мёртвую клавишу
        },
        dead = {
            acute = {
                compose = { ["і"] = "і́", ["е"] = "е́" },   -- акут, затем клавиша, печатающая і / е
                keys = { i = { opt = "!" } },           -- клавиша ⌥ внутри состояния
            },
        },
        terminators = { acute = "´" },                  -- что печатает незавершённая мёртвая клавиша
    },
    ["com.apple.keylayout.Greek"] = { keys = { ["="] = { shift_opt = "≥" } } },  -- только для этой раскладки
}
```

- Ячейка это текст, `{ dead = "<состояние>" }`, `false` (ничего не печатать) или `{ pass = true }` (родное Apple).
- Состояния Бирмана: `acute grave circumflex diaeresis tilde ring caron breve cedilla double_acute`; любое другое имя в `dead` создаёт новое.
- `opt` это правый ⌥ (любой ⌥ при `rightOptionOnly = false`), `shift_opt` это ⇧ + эта клавиша.
- Имена клавиш это позиции QWERTY на любой раскладке; неизвестное имя при вызове `start()` даёт ошибку. Строки `fixups` тоже принимают имена.

### Изменить то, что сделал Бирман

Часть решений Бирмана похожа на ошибки или отличается в его английской и русской раскладках. Spoon
сохраняет их все; каждое исправление это одна запись в `overrides`:

```lua
layer.overrides = {
    ["*"] = { dead = {
        -- ⇧⌥6 дважды: в английской два комбинируемых знака циркумфлекса (U+0302 U+0302), в русской один.
        circumflex = { keys = { ["6"] = { shift_opt = "\u{302}" } } },
        -- ¨, затем ⌥i: в английской акцент и потом і, в русской ï и Ї.
        diaeresis = { keys = { i = { opt = "ï", shift_opt = "Ї" } } },
    } },
    -- В ISO Russian – PC есть вторая клавиша ё (рядом с левым ⇧), которую Бирман не включил в мёртвые
    -- клавиши; так она составляется как первая (˘, затем ё → ӗ).
    ["com.apple.keylayout.RussianWin"] = { dead = {
        breve = { keys = { ["`"] = { base = "ӗ", shift = "Ӗ" } } },
    } },
}
```

`base` и `shift` в `keys` состояния мёртвой клавиши это ячейки для обычной и Shift-клавиши по позиции; они
главнее `compose`, а `{ pass = true }` там значит «эта клавиша не составляет символ»: именно так в раскладке
Бирмана исключена вторая клавиша ё.

### baseFixups

Раскладка Бирмана двигает ещё несколько обычных клавиш: `` ` `` и `~` на ISO-клавише `§`, `\` на ISO-клавише
рядом с левым ⇧ в ABC, `Ё` на ⇧`` ` `` в Russian – PC. `baseFixups = true` печатает их, только для
`com.apple.keylayout.ABC` и `com.apple.keylayout.RussianWin`. Рассчитано на ISO-клавиатуры: на ANSI второй
вариант превратил бы клавишу с обратным апострофом в обратную косую черту, поэтому по умолчанию выключено.
