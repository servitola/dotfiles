# Что печатает какая клавиша

Плакат самого Бирмана с пояснениями, зачем нужны эти символы: <https://ilyabirman.ru/typography-layout/poster/>.

Клавиша с ⌥ даёт нижний символ, с ⇧⌥ верхний. Клавиши в серых квадратиках это мёртвые клавиши: нажмите
акцент, затем букву.

| Что | Как |
| --- | --- |
| длинное тире `—` / короткое `–` | ⌥ + `-` / ⇧⌥ + `-` |
| минус `−` / точка-маркер `•` | ⌥ + `m` / ⇧⌥ + `m` |
| умножение `×` | ⌥ + `x` |
| ёлочки `«` `»` | ⌥ + `,` / ⌥ + `.` |
| лапки `„` `“` | ⇧⌥ + `,` / ⇧⌥ + `.` |
| одинарные `‘` `’` | ⇧⌥ + `k` / ⇧⌥ + `l` |
| угловые `‹` `›` | ⇧⌥ + `9` / ⇧⌥ + `0` |
| неразрывный пробел | ⌥ + пробел |
| `©` `®` `™` | ⌥ + `c` / `r` / `t` |
| `€` `₽` `£` `$` `¢` | ⌥ + `e` / `h` / `f` / `4`, ⇧⌥ + `c` |
| `°` `‰` `′` `″` | ⌥ + `d` / `5` / `p`, ⇧⌥ + `p` |
| `≈` `≠` `±` `∞` | ⌥ + `a` / `=`, ⇧⌥ + `=`, ⌥ + `8` |
| стрелки `←` `↑` `→` `↓` | ⌥ + `9` / `6` / `0` / `v` |
| `✓` `§` `ß` | ⌥ + `w` / `s` / `b` |
| дореволюционные `ѣ` `ѳ` `ѵ` `і` | ⌥ + `y` / `o` / `u` / `i`, с ⇧ заглавные |
| дроби `¹⁄₂` `¹⁄₃` `¹⁄₄` | ⇧⌥ + `2` / `3` / `4` |
| `¡` `¿` | ⇧⌥ + `1` / `7` |

Буквы указаны по QWERTY: раскладка позиционная, как на Windows.
