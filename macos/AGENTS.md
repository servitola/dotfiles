# macos — one-shot macOS system configuration: `defaults` tweaks, per-extension default apps, Dock, hosts.

- `set_default_apps.sh` binds extensions and UTIs to apps from one `HANDLERS` dict. Add an app or an extension there, nothing else. Two rules it enforces: the write goes through `defaults import` (a raw `.plist` write is silently reverted by cfprefsd), and every bundle id must belong to an installed app (a dead id makes macOS ask which app to use). Full filenames (Brewfile/Makefile/…) have no mechanism and are absent. Check a binding by asking `NSWorkspace.urlForApplication(toOpen:)` about a real file — anything that resolves by UTI cannot see the extension bindings.
- Install step 10 (`install/10-dock.sh`) sets the Dock: on the right, only Apps in it. It writes only what differs and restarts the Dock only then.
- `helpers/` holds sourced functions shared with `macos_cleanup/`: `colors.sh`, `spinner.sh`, `try_to_clean_directory.sh`, `try_to_clean_by_pattern.sh`.
- `hosts` is symlinked to `/etc/hosts` by install step 5; it null-routes telemetry domains (Anthropic, VS Code, Microsoft, analytics).
- macOS settings are install step 1 (`install/01-macos-defaults.sh`): one table, a row per setting, written only when the value differs. `set_default_apps.sh` is step 9. Not run automatically otherwise.
- Standalone utilities (not part of `make`): `git-repo-analyzer.sh` (find/prune git repos), `move-addictive-drums-to-external.sh` (migrate AD2 samples to external drive + symlink), `update_all_and_cleanup_all.sh` (convenience wrapper that sources `macos_update/update_all.sh` then `macos_cleanup/cleanup_all.sh`).
- Sibling dirs `macos_update/` (brew/npm/macOS updates) and `macos_cleanup/` (cache/log pruning) are separate; this dir is config/setup, they are maintenance. They meet only via `update_all_and_cleanup_all.sh` and the shared `helpers/try_to_clean_*` scripts.
