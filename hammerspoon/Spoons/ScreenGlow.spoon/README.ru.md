# ScreenGlow.spoon

[English](README.md)

Края экрана светятся, пока ИИ-агент управляет вашим Mac. Не трогайте мышь, пока свечение не погаснет.

- Мягкая пульсация по краям каждого экрана, на всех мониторах.
- Активное окно подсвечено, остальное затемнено.
- От кликов расходятся круги: видно, куда кликает агент.
- Таймер в строке меню; клик по нему гасит свечение.
- Строка текста внизу экрана: что агент сейчас делает.
- Сторожевой таймер: упавший агент не оставит экран светиться.

## Установка

Распакуйте `ScreenGlow.spoon.zip` из [последнего релиза](https://github.com/servitola/ScreenGlow.spoon/releases/latest) в `~/.hammerspoon/Spoons/`, затем в `~/.hammerspoon/init.lua`:

```lua
require("hs.ipc")
hs.loadSpoon("ScreenGlow")
```

`hs.ipc` даёт агенту достучаться до Hammerspoon из терминала командой `hs`. Если команда `hs` не находится, один раз выполните `hs.ipc.cliInstall()` в консоли Hammerspoon.

## Как пользоваться

```sh
hs -c 'spoon.ScreenGlow:pulse(300)'                           # светиться до 5 минут
hs -c 'spoon.ScreenGlow:pulse(60, "act", "Заполняю форму")'   # цвет и подпись
hs -c 'spoon.ScreenGlow:beat()'                               # вспышка: что-то произошло
hs -c 'spoon.ScreenGlow:stop()'                               # плавно погасить
```

| Вызов | Что делает |
|---|---|
| `pulse(seconds, phase, text)` | Включает свечение или продлевает его до `seconds` от текущего момента. Всё необязательно: 45 с, `think`, без подписи. |
| `beat()` | Короткая вспышка, если свечение включено. |
| `stop()` | Плавно гасит. |
| `active()` | `true`, пока светится. |

Фазы: `think` оранжевая, `act` бирюзовая, `wait` красная (агент ждёт вас).

Как научить агента включать свечение: в [docs/claude-code.ru.md](docs/claude-code.ru.md) — хуки для Claude Code.

## Настройки

Поля `spoon.ScreenGlow`, задаются после `hs.loadSpoon`:

```lua
spoon.ScreenGlow.phases.act = { hex = "#4f9dff" }
spoon.ScreenGlow.sound_start = nil   -- без звука при включении; sound_stop тоже можно nil
spoon.ScreenGlow.alpha_max = 0.6     -- пульсация спокойнее
```

Все поля со значениями по умолчанию — в начале [init.lua](init.lua): слои и ширина свечения, период пульсации, появление и затухание, затемнение, рамка активного окна, круги от кликов, размер подписи, звуки.
