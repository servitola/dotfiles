# The "So You Need A Typeface" decision tree

Full transcription of Julian Hansen's poster *So You Need A Typeface* (julianhansen.com),
read from the Russian translation by xtotdam.

The poster's own framing: *"An alternative way to pick a typeface (or just find inspiration)
for a project, without leafing through every page of FontBook. The list is (very loosely)
built on 50 of the 100 Best Typefaces according to FontShop."* It ends at 40 named faces.

**Start with what you need it for.** Five entry points: BOOK · INFOGRAPHIC · NEWSPAPER ·
LOGO · INVITATION.

A few dense clusters on the poster route ambiguously — dotted lines cross and answers sit on
whichever side had room. Those spots are marked `~` and resolved the way the joke reads.
Everything unmarked is unambiguous on the poster.

## BOOK

```
BOOK
└─ Completely at a loss?
   ├─ YES → Caslon                        ("when in doubt, use Caslon")
   └─ NO  → Then the comfort champion?
            ├─ YES → Minion
            └─ NO  → Everybody loves Garamond
                     ├─ YES → But maybe something bigger?
                     │        ├─ YES → Sabon
                     │        └─ NO  → Garamond
                     └─ NO  → So you want a sans, then?
                              ├─ YES → Optima
                              └─ NO  → What's your opinion on Eric Gill?
                                       ├─ FINE → Joanna
                                       └─ BAD  → Do humanist forms please your eye?
                                                 ├─ YES → Baskerville
                                                 └─ NO  → Hmm, then let's talk food
                                                          ├─ GOUDA    → FF Scala
                                                          └─ EMMENTAL → Syntax
```

### The classic / office side branch

Reached from the sans/serif questions above; on the poster it hangs off the same cluster. `~`

```
A whole pile of office correspondence?
├─ YES → Then something classic awaits you → OK →  Palatino · Lexicon · Fedra
└─ NO  → How does semi-sans-semi-serif sound?
         ├─ FINE → Rotis
         └─ BAD  → Something new, with both sans and serif cuts?
                   ├─ FINE → Fedra
                   └─ BAD  → Is this for an Italian restaurant?
                             ├─ YES → Palatino
                             └─ NO  → Rotis
```

## INFOGRAPHIC

```
INFOGRAPHIC
└─ We all love something condensed, right?
   ├─ YES → Univers
   └─ NO  → Packed with tables, isn't it?
            ├─ YES → Letter Gothic
            └─ NO  → Did you cry watching "The Terminator"?
                     ├─ YES → OCR
                     └─ NO  → I have to say, this chart looks pretty cool
                              └─ YES → FF DIN
```

## NEWSPAPER

Split first by what the type does on the page: **TEXT**, **DISPLAY**, or **A MIX**.

### Text

```
TEXT
└─ Do people call you boring now and then?
   ├─ YES → Times
   └─ NO  → How about something that's in use all the time?
            ├─ YES → Miller
            └─ NO  → How about a revival of American traditions?
                     ├─ FINE → Proforma
                     └─ BAD  → The Netherlands is quite nice, though, isn't it?
                               ├─ YES → Mmm, sharp serifs are good → OK → Swift
                               └─ NO  → Get out of my sight!!      → Comic Sans
```

### A mix

```
A MIX
└─ Do you think Mr. Spiekermann is right about most things?
   ├─ YES → Arnhem                                                   ~
   └─ NO  → The Netherlands is quite nice, though, isn't it? → (as above: Swift / Comic Sans)
```

### Display

```
DISPLAY
└─ Rather traditional?
   ├─ YES → Do you like road signs?
   │        ├─ YES → Okay, about its age
   │        │        ├─ NOT MUCH → Helvetica            (Interstate hangs off this cluster) ~
   │        │        └─ QUITE A LOT → Franklin Gothic
   │        └─ NO  → Is it okay if it comes from Switzerland?
   │                 └─ YES → Helvetica
   └─ NO  → Something modern, even outspoken?
            ├─ YES → Gotham
            └─ NO  → Not afraid they'll ask whether you're stuck in the 90s?
                     ├─ NOT AFRAID → Helvetica
                     └─ AFRAID     → FF Meta
```

Downstream of Helvetica / Interstate the poster keeps going:

```
If I say "sci-fi is my favourite genre"
├─ FINE → Eurostile
└─ BAD  → FF Meta
```

## LOGO

Two openings: **Sans serif, probably?** and **Or maybe with serifs?**

### Sans serif, probably?

```
Do you like geometry?
├─ YES → Then good, follow me → Do you like Futura?
│                               ├─ YES → Futura
│                               └─ NO  → Metro
└─ NO  → Maybe a neo-grotesque?
         ├─ YES → Okay, about its age → NOT MUCH → Helvetica / QUITE A LOT → Franklin Gothic
         └─ NO  → Then something humanist?
                  ├─ YES → Do you like Adobe?
                  │        ├─ YES → Myriad
                  │        └─ NO  → Frutiger
                  └─ NO  → How about a classic, in that case?
                           ├─ YES → Akzidenz Grotesk
                           └─ NO  → Well then... only the decorative one → OK → Peignot
```

### Or maybe with serifs?

Runs into the newspaper display cluster (`Rather traditional?` → road signs → Interstate,
age → Helvetica / Franklin Gothic) and the sci-fi question above. `~`

## INVITATION

```
INVITATION
└─ Something handwritten, don't you think?
   ├─ YES → Something calligraphic, maybe?
   │        ├─ YES → Zapfino
   │        └─ NO  → FF Erikrighthand
   └─ NO  → Or something quirky?
            ├─ YES → Thin lines        → Bodoni
            │        Even thinner lines → Readability?
            │                             ├─ YES → Walbaum
            │                             └─ NO  → Didot
            └─ NO  → Something fun, huh? → Are you alone?
                     └─ YES → Then good, follow me → Do you like Futura?
                                                     ├─ YES → Futura
                                                     └─ NO  → Metro
```
