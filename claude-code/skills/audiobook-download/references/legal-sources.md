# Legal free-audiobook sources

Everything here is legal: public domain, author/publisher-authorized, or
library lending backed by an actual license. None of it is scriptable in
the same one-two-punch way as archive.org, so treat this as a browsing
list to hand the user — not something to scrape automatically.

## Public domain (out-of-copyright works)

- **LibriVox** (librivox.org) — volunteer-read public-domain books.
  Already covered by the main workflow via archive.org, but the site
  itself is also browsable directly.
- **Internet Archive** (archive.org) — the main workflow's source; also
  browsable directly at archive.org/details/librivoxaudio and
  archive.org/details/audio_bookspoetry.
- **Loyal Books** (loyalbooks.com) — public-domain audiobooks + ebooks in
  29 languages, no API, browse/download from the site.
- **Lit2Go** (etc.usf.edu/lit2go) — USF collection of public-domain
  stories/poems as MP3 + PDF transcript, aimed at classroom use. Caps
  downloads at 25 files per non-commercial project; more requires
  permission from USF's FCIT.
- **Open Culture** (openculture.com/freeaudiobooks) — curated list of
  free audiobooks (mostly classics) plus free courses/language lessons.
- **StoryNory** (storynory.com) — free children's audio stories,
  original + public-domain fairy tales.

## Legal but not "download and keep" — library lending

These require a real library card (most public libraries worldwide
support digital cards, some issuable online) and stream/lend rather than
give a permanent file — fully legal because the library pays licensing:

- **Libby / OverDrive** — borrow audiobooks with a library card, app-based
  (no scriptable download; DRM-protected on purpose).
- **Hoopla** — similar model via participating libraries.
- Russian equivalents: **ЛитРес** (some free/promo titles, library
  partnership program "ЛитРес: Библиотека" often free with a library
  card), **Строки** (Sberbank, free public-library audiobooks with a
  library card).

## What's deliberately excluded

Sites that host copyrighted commercial audiobooks (recent releases,
paid narrators, publisher-owned catalogs) "for free" without a license
are not included — that content is there without the rights holder's
permission, i.e. piracy, regardless of how the site brands itself. If a
requested title only shows up on such sites, that's a signal it's still
under copyright and not legally free anywhere — say so rather than
substitute a pirated link.
