# Журнал изменений

## 0.1.0

Первый релиз. Правила `{ match, open, from }` проверяются сверху вниз: Lua-шаблон, список шаблонов или функция; имя браузера, bundle id или функция; при желании — только для ссылок из заданных приложений. Готовые `localNetwork` и `slackRedirect`, `unwrap` для ссылок в обёртках, `route()` — проверить правило, ничего не открывая. Ссылки открываются через `open -b`; настройки проверяются в `start()`.
